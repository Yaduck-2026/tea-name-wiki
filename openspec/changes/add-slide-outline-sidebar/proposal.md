# Proposal

## Why

教學簡報有 15 張，目前只能一張張翻頁，或手動改網址 `#N` 跳頁。上課或複習時想直接跳到「六大茶類」「沖泡」等段落很不方便。使用者希望在側邊欄列出每張投影片，點一下就跳到該頁。

## What Changes

- 簡報頁新增「投影片目錄」側邊欄：依序列出每張投影片的編號與標題（取自 `deck.json`，不需另外維護），點選即跳到該張；目前所在的那一張會標示出來。
- 頂端列新增「目錄」按鈕，讀者可隨時自行開啟或隱藏側邊欄；選擇會記在讀者自己的瀏覽器，下次開啟簡報時維持（使用者確認）。
- 桌機寬度：第一次開啟時側邊欄預設隱藏、投影片全寬；開啟後固定在左側，投影片在右側。之後依讀者上次的選擇。
- 手機與窄螢幕：側邊欄每次都預設收起（不套用記住的選擇，避免一開啟就蓋住投影片），按「目錄」從左側滑出覆蓋在投影片上；選了某張、按 Esc 或點遮罩就關閉。
- 鍵盤可用：目錄是一般連結，可用 Tab 移動、Enter 跳頁；開啟時焦點移到目前那一張，關閉時焦點回到「目錄」按鈕。原有的方向鍵翻頁不變。

## Capabilities

### New Capabilities

（無）

### Modified Capabilities

- `teaching-slides`：新增「投影片目錄側邊欄」需求。原有的「簡報瀏覽操作」需求不變。

## Impact

- 修改：`site/slides.html`（側邊欄與「目錄」按鈕）、`site/slides.js`（產生目錄、標示目前張數、開關）、`site/slides.css`（桌機兩欄與手機抽屜版面）。
- 不影響：建置程式、檢查程式、`deck.json` 格式、Wiki 內容、讀者站。
- 驗證以瀏覽器實測為主（目前專案沒有前端 JS 的自動測試）；另在建置測試確認輸出的簡報頁含有目錄區塊。

## 假設（請審閱）

- 桌機與手機的分界沿用 760px 左右（與目前圖片版面的切換點一致）。
- （已確認）記住桌機的開關選擇，第一次預設隱藏；只存在讀者自己的瀏覽器（localStorage），讀取失敗或無法儲存時就用預設隱藏，不影響使用。
- 目錄只列標題，不顯示縮圖。
