# 茶名有解｜台灣茶知識 Wiki

從一個完整茶名開始，拆解產地、品種與風格，串接六大分類；整理近一週茶知識社群討論並查證，留下可追溯來源。

這是以 `AGENTS.md` 驅動 AI 協作維護的課堂專案。LLM 協助整理及更新內容，網站首版不提供即時聊天。

內容由使用者手動要求搜尋／更新時才整理，不設定自動搜尋或定期更新。網站顯示的觀察日期保留為實際研究當時的日期。

## 可重複使用的流程

研究並保存可讀來源 → 複製模板 → 填寫查證過的內容 → 以 ID 建立關聯 → 檢查 → 建置 → 更新網站。

新增一篇內容不應重做整個網頁。後續建置器會從結構化資料產生索引、頁面及搜尋資料，並排除草稿。
