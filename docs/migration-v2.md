八個外部來源的舊目錄有網址、支持範圍及先前查閱紀錄，但沒有保存原文。本次移到 raw/references 的是這份已取得的定位紀錄，不能冒充網頁全文。

wiki/sources 則是可繼續維護的摘要頁，會說明支持哪些內容及有哪些限制。未來手動授權查找後，才取得可合法保存的新來源版本，不回填假快照。
